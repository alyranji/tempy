## 📖 معرفی پروژه

**Tempy** یک پلتفرم مدرن و کاربردی برای خرید و فروش قالب‌های وب‌سایت آماده است. این پلتفرم به توسعه‌دهندگان و کسب‌وکارها این امکان را می‌دهد تا قالب‌های طراحی شده خود را به راحتی به فروش رسانده و از بین صدها قالب متنوع، بهترین گزینه را برای پروژه‌های خود انتخاب کنند.

## ✨ ویژگی‌های کلیدی

### 🎨 برای خریداران

- **📚 گالری قالب‌های متنوع** - دسترسی به مجموعه‌ای گسترده از قالب‌های مختلف
- **🔍 جستجوی پیشرفته** - فیلتر کردن بر اساس دسته‌بندی، قیمت، امتیاز و ویژگی‌ها
- **⭐ سیستم امتیازدهی و نظرات** - مشاهده تجربیات سایر کاربران
- **📱 طراحی واکنش‌گرا** - تجربه کاربری یکسان در تمام دستگاه‌ها
- **🛒 فرآیند خرید آسان** - خرید سریع و امن قالب‌ها

### 🛠️ برای فروشندگان

- **📤 آپلود آسان قالب** - بارگذاری ساده قالب‌ها با جزئیات کامل
- **📊 پنل مدیریت** - مدیریت موجودی، قیمت‌ها و آمار فروش
- **💬 سیستم نظرات** - تعامل مستقیم با مشتریان
- **📈 آمار و گزارش‌ها** - پیگیری عملکرد فروش

## 🏗️ معماری فنی

### فناوری‌های اصلی

- **⚡ Next.js 14** - فریم‌ورک React برای تولید اپلیکیشن‌های مدرن
- **🔷 TypeScript** - توسعه ایمن و قابل اطمینان
- **🎨 CSS Modules** - استایل‌دهی ماژولار و بدون تداخل
- **🗄️ Prisma ORM** - مدیریت پایگاه داده با Type Safety
- **🐬 MySQL** - پایگاه داده رابطه‌ای قدرتمند

### ابزارهای توسعه

- **🔍 ESLint** - آنالیز کد و حفظ کیفیت
- **💅 Prettier** - فرمت‌دهی یکپارچه کد
- **🎯 TypeScript Strict** - توسعه با بالاترین سطح ایمنی نوع

## 🗃️ مدل‌های داده

### 👥 کاربران (Users)

- اطلاعات پروفایل کاربران
- سیستم احراز هویت
- نقش‌های کاربری (خریدار/فروشنده)

### 🎨 قالب‌ها (Templates)

- اطلاعات کامل قالب‌ها
- تصاویر و دمو
- قیمت‌گذاری و آمار فروش
- دسته‌بندی و تگ‌ها

### 💬 نظرات (Comments)

- سیستم امتیازدهی و بررسی
- تعامل بین کاربران
- مدیریت محتوا

npm run lint
